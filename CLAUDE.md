## a) Project overview

- **Name:** Bajr Vijay Veer Army Academy (short: BVV Army Academy)
- **What it is:** coaching for government-job exams (Defence, Police, Railway, Bank, SSC, State exams) with **study classes + physical training**, **online and offline**.
- **Target users:** students (10th pass, 12th pass, graduates, NCC certificate holders) and their parents.
- **Goal:** a fast, mobile-first, 3-language (English / Hindi / Hinglish) marketing website deployed on GitHub Pages.

## e) Language rules

- Languages: **English (`en`)**, **Hindi (`hi`)**, **Hinglish (`hinglish`)**. **Default: Hinglish.** Saved in `localStorage` key `bvv.language`.
- `<html lang>` is set to `en` / `hi` / `hi-Latn`; `data-script="devanagari"` switches the font for Hindi automatically.
- **No hardcoded visible text, ever.** Every string goes into **all 3** locale files; `npm run check:i18n` must pass (CI runs it).
- Key convention: `section.element.label`, e.g. `hero.cta.primary`, `courses.items.<id>.name`, `categories.items.<id>`. Data-driven text uses the data `id` as the key.
- Interpolation uses named values (`{{value}}`, `{{months}}`). **Do not use i18next's `count`** (plural rules): `hinglish` is not a real locale code for `Intl.PluralRules`.
- Numbers and prices: use `formatNumber` / `formatPrice` from `src/i18n/format.ts` (Indian grouping).
- **Hinglish style:** Hindi words in Roman script, simple and conversational, English for exam/tech terms. E.g. "Apni taiyari aaj se shuru karein", "Free Demo Book Karein", "Courses Dekhein".
- **Hindi:** proper Devanagari, commonly used loanwords in Devanagari (कोर्स, बैच, ट्रेनर्स), no negative letter-spacing, and never fixed heights on text.

## f) Coding rules

- TypeScript, functional components, **one section per file** in `src/sections/`.
- Mock data lives **only** in `src/data/`.
- **Tailwind only, using design tokens.** No inline `style`, no arbitrary values (`w-[123px]`) and no arbitrary variants (`has-[...]`). Need a value? Add it to `tokens.ts` first.
- Use `cn()` from `src/lib/cn.ts` to join classes; use `textStyles.*` and `focusRing` from tokens.
- Section links: navigation to a section uses `useScrollToSection()` (buttons), never `href="#id"` (keeps URLs clean). Each `Section` has `scroll-mt` to clear the sticky header.
- Positioned children: `Card` is `relative`. Any new scroller item containing `absolute`/`sr-only` content must have a positioned ancestor inside the scroller, or it widens the page.
- **Accessibility:** alt text on every image (ImagePlaceholder requires `alt`); one `h1` per page, then h2 per section, h3/h4 inside; visible focus ring (`focusRing`) on all interactive elements; `aria-labelledby` on sections; respect `prefers-reduced-motion`.
- **Images:** placeholders until real ones are provided. Put files in `src/assets/images/` and pass them via `src`:
